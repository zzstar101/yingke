# 强智教务接口研究（公开脱敏版）

> 来源：2026-11-18 的广应科强智教务接口实测记录。原材料包含真实账号和个人学籍信息；本公开版本**刻意不复制**用户名、密码、Cookie、个人姓名、学号、身份证信息及原始业务响应。接口已验证不等于官方提供公共开放 API 或批准第三方访问。

## 站点与响应形式

- 实例根地址：https://jw.educationgroup.cn/gzasc_jsxsd/
- 类型：湖南强智教务系统；浏览器 Web 登录与 HTML 页面。
- 主要业务返回 HTML，不是标准 JSON API。
- 浏览器态依赖 JSESSIONID 以及站点自身下发的其他 Cookie；由客户端 CookieJar 正常处理，不能手工只保留单个字段。
- 访问涉及 User-Agent、Referer 校验以及可能的 WAF 行为；应尊重网站访问策略、限流和用户授权。

## 已验证认证流程

1. GET /gzasc_jsxsd/verifycode.servlet：获得验证码图，并建立对应会话 Cookie。
2. POST /gzasc_jsxsd/xk/LoginToXk：提交用户输入的账号、密码与验证码。
3. GET /gzasc_jsxsd/framework/xsMain.jsp：完成站点所需的会话激活。
4. 再访问被授权的业务页面。

**关键注意事项**：
- 不能跳过会话激活，否则业务页面可能重定向回登录入口。
- 传统网页前端会进行 Base64 编码，但 Base64 **不是加密**；不要把它视为额外密码保护。
- 不要在 GitHub 中保存登录表单中的真实值，也不要将认证过程打印到日志。
- 明确区分会话过期、未激活、WAF/Referer 拦截以及普通网页解析错误。
- 验证码应由用户正常完成；不要频繁重试账号密码以避免锁定/风控。

## 课程表

- 首次 GET /gzasc_jsxsd/xskb/xskb_list.do 获取学期、周次、节次方案字段。
- POST 同一路径以查询所选学期及周次；节次方案参数从页面动态提取，不应硬编码。
- 学期字段为 xnxq01id；教学周字段为 zc。
- 课表 HTML 表格标识为 kbtable，列为周一到周日。
- 行首可能是 th 而非 td；省略这一列会造成日期错位。
- 单元格内既有展示态 kbcontent1，也有包含老师信息的 kbcontent；需要排除空壳节点。
- 一格可能有多段课程，可能包含同一门课因老师或周次不同产生的多段记录。
- 非连续周次需要保存完整周集合，不可仅保存起止周。
- 节次作息时间由页面提供；不能默认全校通用固定时间表。

## 成绩

- GET /gzasc_jsxsd/kscj/cjcx_list 使用开课学期 kksj 等筛选字段。
- 返回表格标识 dataList。
- 可以得到课程编号、课程名、成绩、学分、学时、绩点、考试性质、课程性质、课程属性等。
- 支持按学期查询以及空结果场景；空结果不能当作接口错误。
- GPA 等派生统计需要先明确采用的学校规则，不能凭少量数据反推通用算法。

## 考试安排

- GET /gzasc_jsxsd/xsks/xsksap_list。
- 学期字段为 xnxqid，**不同于课表的 xnxq01id**。
- 支持期初、期中、期末等过滤参数。
- 已验证接口返回和“当前学生没有考试安排”的空态；**还没有使用真实考试条目验证字段解析**。

## 培养方案

- GET /gzasc_jsxsd/pyfa/pyfa_query：已验证 HTTP 200，页面含相关表格。
- 培养方案字段的归一化解析与完整数据模型仍待确认。

## 其他已探测页面与边界

- /gzasc_jsxsd/grxx/xsxx：学籍信息页面可访问；数据包含高度敏感字段，当前产品仅作技术研究，不采集无关字段。
- 选课入口不是简单 GET 即可用；直接访问遇到入口上下文限制，**选课不在当前需求范围**。
- 空教室接口未验证，**也不在当前已确认功能范围**。

## 解析和同步注意事项

- 当前学期应读取页面实际 selected 的选项，**不能取学期列表第一项**：列表首项可能是未来学期。
- 参数、表格结构、课时方案都应从有效响应解析，避免硬编码。
- 解析失败保留上次可用缓存并展示“同步失败”，不可把错误 HTML 当作空数据覆盖本地记录。
- 建议对同一账号的请求串行控制并进行节流；实测记录采用请求间隔不短于 1.2 秒，但这只是当时的保守实践，并非官方限额。
- 只为成功认证且有授权的学生查询本人数据。不要运行大规模账号测试、凭据探测或绕过网站限制。
