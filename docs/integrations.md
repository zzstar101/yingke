# 校园平台接入矩阵

> 状态按“用户已确认功能”和“技术已验证”分开。除强智教务外，以下平台的可调用接口和许可范围仍需进一步调查。

| Provider | 认证关系 | 功能范围 | 技术现状 |
| --- | --- | --- | --- |
| LearningPlatform / 学习通 | 学习通独立账号 | 课程、作业、考试、图书馆、图书检索、智慧微空间预约 | 账号体系已知；业务接口未验证 |
| Academic / 强智教务 | 独立教务用户名/密码 | 课表、成绩、考试安排、培养方案 | 已实现 iOS 只读接入，真机已验证官方授权、课表读取与切周。真实考试条目与培养方案字段仍待验证。 |
| UnifiedIdentity / 统一认证 | 独立登录体系，与教务密码不保证一致 | 流程审批、实验室预约、校园 WebVPN | 功能归属已知；登录及数据接口未验证 |
| SecondClass / 到梦空间 | 独立账号密码 | 活动浏览/报名、现场二维码签到、二课学分、热门/最新、关注部落同步、新活动提醒 | 产品需求已确认；可用接口及推送数据源待验证 |

## 接入原则

1. 接入界面采取按需绑定，一个 Provider 连接成功即可使用自己的功能。
2. 学习通下的图书馆、微空间等模块虽归属同一账号体系，暂不假定共享相同 Cookie/Token。
3. 不将教务账号和统一认证账号自动合并；账号相同不等于会话相同。
4. 会话与 API 错误分开报告，单平台故障不影响其他平台。
5. 含写操作的功能必须对接官方流程并验证提交结果；不以绕过验证码、时间或位置校验为目标。

## 暂缓：水电费

用户既有研究项目：[GZASC-electricity-monitor](https://github.com/zzstar101/GZASC-electricity-monitor)。

已知模式是**微信网页 OAuth + 独立网站 JSESSIONID**，电费余额/电量可在有效会话下查询。普通手机浏览器打开只能看到没有数据的骨架；网站目前仅提供 HTTP。该脚本并没有实现可直接嵌入原生 APP 的微信 OAuth 授权流程。

正式产品暂不接入，也不向普通用户提供导入抓包 Cookie 的连接方式。需要先确认合规授权方式及安全传输能力。

## 明确排除

- 校园网认证、套餐或自动重连
- 企业微信校园邮箱及其网页版聚合
- APP 自有认证、论坛、云端凭据同步

## 当前最有价值的验证工作

- 学习通：课程/作业/考试与图书馆/微空间是否分别需要额外的子会话，以及各接口的授权边界。
- 统一认证：流程审批、实验室预约与 WebVPN 的具体站点和跳转链路。
- 到梦空间：活动、二课学分、已关注部落和新活动信息是否可在允许范围内读取；报名与二维码签到是否支持原生界面的官方接口操作。
- 教务：培养方案结构解析、真实考试记录、课表日期/周次边界回归；选课/空教室目前未纳入确认的产品功能。
